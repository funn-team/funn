# Funn Brand Guidelines

## Brand idea

**Funn = finding made simple.**

The identity is designed for a compact marketplace: clear, useful, modern and easy to recognize at small sizes.

Recommended line:
**Find it. List it. Funn.**

## Primary direction

Use **Concept A — Signal F** as the main identity.

Why:
- reads as an abstract `F` without depending on text
- layered ribbons suggest listings / discovery / movement
- remains legible as a favicon and GitHub avatar
- works naturally with Funn's existing dark UI
- does not imitate finn.no's identity

## Logo hierarchy

1. `funn-mark-gradient.svg` — primary standalone mark
2. `funn-lockup-dark.svg` — primary horizontal lockup on dark surfaces
3. `funn-lockup-light.svg` — horizontal lockup on light surfaces
4. monochrome marks — only when gradients are unsuitable

Do not:
- stretch or skew the mark
- recolor individual pieces arbitrarily
- add shadows, outlines or glow to the logo itself
- place detailed imagery directly behind the mark

## Clear space

Keep free space around the mark equal to roughly **25% of the mark width**.
For the horizontal lockup, use at least the height of the lowercase `u` as surrounding clear space.

## Minimum size

- favicon: 16 × 16 px
- general UI icon: 24 × 24 px minimum
- standalone brand mark: 32 × 32 px minimum
- lockup with wordmark: 120 px wide minimum

## Colors

| Role | Hex |
|---|---|
| Background | `#0D1117` |
| Surface | `#161B22` |
| Text | `#F0F3F6` |
| Muted text | `#8B949E` |
| Blue | `#2F81F7` |
| Cyan | `#22D3EE` |
| Violet | `#8B5CF6` |
| Pink accent | `#D946EF` |

The primary product color should remain **blue**. Violet and cyan support the brand; pink is a small endpoint accent, not a primary UI color.

## Typography

Preferred: **Inter**  
Fallback: `ui-sans-serif, system-ui, sans-serif`

No font files are included in the pack.

Suggested weights:
- 700–800: logo-adjacent headlines
- 600: buttons / labels
- 400–500: body copy

## GitHub usage

- Organization avatar: `03_github/funn-github-org-avatar-500.png`
- Repository/social icon: `03_github/funn-repo-social-icon-400.png`
- README header: `04_social/funn-readme-header-1280x640.png`

## App icon usage

Use the dark-tile gradient icon for app icons and GitHub. Transparent logo assets are better for the website header and documents.

## Concept alternatives

- **A — Signal F:** recommended. Most ownable and scalable.
- **B — Search Loop:** more literal marketplace/search metaphor; less unique.
- **C — Pin F:** location/discovery feel; visually strong but implies maps, which are not core to the current app.

## Accessibility

The brand gradient is decorative. Do not use gradient text for essential UI labels.
Keep functional UI contrast based on solid colors.
